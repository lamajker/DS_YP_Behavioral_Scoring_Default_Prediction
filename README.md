# DS_YP_Behavioral_Scoring_Default_Prediction
Модель поведенческого скоринга для прогнозирования дефолта клиентов банка

## Описание проекта

В проекте разработана модель поведенческого скоринга для прогнозирования дефолта клиентов банка.

Цель проекта - построить устойчивую ML-модель, которая позволяет прогнозировать вероятность дефолта клиента и одновременно удовлетворяет бизнес-ограничениям банка:

- approval_rate ≥ 65%
- default_rate ≤ 2%
- missed_defaults_rate ≤ 4%

Проект включает полный цикл разработки скоринговой модели:

- подготовку и анализ данных;
- построение и сравнение моделей;
- балансировку классов;
- временную кросс-валидацию;
- подбор гиперпараметров через Optuna;
- калибровку вероятностей;
- поиск оптимального бизнес-порога;
- анализ важности признаков;
- финальную оценку устойчивости модели.

## Подготовка данных

В проекте использовались данные клиентов банка:

- финансовые признаки;
- транзакционная активность;
- MCC-категории расходов;
- кредитная нагрузка;
- доход клиента;
- история взаимодействия с банком.

Данные были разделены с учетом временной структуры:

- train - обучение модели;
- calibration - калибровка вероятностей и подбор порога;
- test - финальная проверка модели.

Такой подход позволил избежать утечки данных.

## Подход к моделированию

Были протестированы:

- Logistic Regression;
- Random Forest;
- модели с балансировкой классов;
- модели без балансировки.

Для оценки использовались:

- Accuracy;
- ROC-AUC;
- Approval Rate;
- Default Rate;
- Missed Defaults Rate.

Лучший результат показал Random Forest с балансировкой классов через RandomUnderSampler.

## Подбор гиперпараметров


## Калибровка вероятностей

Для повышения качества вероятностных предсказаний использовалась:

```python
CalibratedClassifierCV(method='sigmoid')
```

Качество калибровки оценивалось через коэффициент Бриера.

Результат:

- Brier score до калибровки: 0.1083
- Brier score после калибровки: 0.0725
